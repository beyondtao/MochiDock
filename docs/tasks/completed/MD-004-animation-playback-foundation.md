# MD-004：动画播放与状态基础

## 任务信息

- 状态：已完成
- 任务类型：阶段 1B 技术基础
- 产品负责人：用户
- 项目管理与验收：高级项目经理 Agent
- 开发执行：Codex 开发部门
- 前置依赖：v0.4 趴姿透明母版及由其确定性生成的尺寸素材已获用户确认

## 任务目标

在不改变现有单面板、拖动、尺寸和隐藏/恢复闭环的前提下，将已确认的 v0.4 趴姿素材接入应用，并通过底部锚定的轻微纵向缩放实现首轮可试用呼吸；同时建立足以支持阶段 1B 后续眨眼与点击回应的轻量动画状态基础。

## 开发范围

- 将默认站姿替换为已确认的 v0.4 趴姿透明素材，保持 80/120/160 三档并根据用户在 16 英寸 MBP 上的验收反馈新增 240/320 两档；默认仍为 120。
- 补齐 1024×1024 App Icon 及 macOS 所需全部尺寸槽位；将 Asset Catalog 按系统资源、角色、姿势与版本建立可扩展分类，保持现有资源名不变。
- 呼吸完全复用同一张透明素材，以底部为锚点做轻微纵向缩放；不得重新生成或切换呼吸图片帧。
- 首轮参考峰值约为预览中的 2.4%，开发部门可在不超过该视觉强度的范围内选择更适合 SwiftUI 的精确值，并集中配置。
- 呼吸采用缓慢、平滑的起伏并保留明显静止间隔，不持续快速循环；节奏参数需集中、可调整。
- 为后续透明图像帧动作保留按指定顺序与节奏播放的最小能力，但本任务不接入未确认的眨眼或点击正式素材。
- 建立最小状态边界：待机、点击回应、恢复待机。
- 点击回应播放期间不重复创建计时器或无界排队动作。
- 尺寸切换、Hide/Show 和面板复用后，播放系统仍保持稳定。
- 以可注入的时钟、调度或等价设计保持关键状态可测试，具体实现由开发部门决定。

## 明确非目标

- 不制作或重新生成正式角色素材。
- 不接入鼠标跟随、自动走动、飞行、睡觉或多种随机行为。
- 不保存状态、位置或设置。
- 不引入第三方动画框架。
- 不改变签名、Bundle Identifier、deployment target 或发布配置。

## 验收标准

### 自动验证

- 默认角色资源为 v0.4 趴姿，并正确对应 80/120/160/240/320 五档尺寸。
- App Icon 拥有 1024×1024 不透明源图，macOS AppIcon 槽位完整，Asset Catalog 分类后仍能正常编译并加载五档角色资源。
- 呼吸缩放以底部为锚点，峰值不超过确认预览的视觉强度，结束后回到原始比例。
- 待机可长时间停留，呼吸之间存在明显静止间隔，不持续快速晃动。
- 最小动画状态可以回到待机，后续短促动作不会要求重建播放架构。
- 快速连续点击不会导致无界动作队列或错乱状态。
- 原有交互、尺寸、面板与菜单测试继续通过。

### 运行验证

- 启动后显示趴姿小熊猫，并可观察到轻微、缓慢、无背景闪烁的呼吸起伏。
- 呼吸过程中角色纹理、透明边缘和底部位置稳定，没有逐帧重绘造成的闪烁。
- 拖动、尺寸切换、Hide/Show 与 Quit 未被破坏。
- Debug 构建成功，全部有效测试通过。

## 风险与停止条件

- 如果必须引入第三方依赖、大规模重写视图/窗口结构或新增持久化，停止并由用户决定。
- 动画架构只服务已确认的程序化呼吸和后续单次短促动作，不为未承诺的复杂行为提前设计平台。
