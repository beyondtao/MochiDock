# MD-002：正式角色静态接入与桌面尺寸验证

## 任务信息

- 状态：已完成
- 任务类型：角色素材接入与体验验证
- 产品负责人：用户
- 项目管理与验收：高级项目经理 Agent
- 开发执行：Codex 开发部门
- 创建日期：2026-07-19

## 任务目标

以用户确认的小熊猫 v0.3 静态母版替换临时 SwiftUI 占位形象，并在真实桌面环境比较 80、120、160 三档显示尺寸，同时保持 MD-001 的单面板、拖动、点击、恢复和退出闭环。

## 开发范围

- 将 80、120、160 三张透明 PNG 分别放入独立 image set。
- 默认使用 120，并提供不持久化的菜单栏尺寸切换。
- 尺寸切换保持窗口中心、当前互动状态和同一个 `NSPanel`。
- 保留 `Resting` / `Happy` 状态，以短促程序动效表现点击反馈。
- 保留透明无边框、拖动、`Show Pet`、`Quit MochiDock` 和辅助功能信息。

## 明确非目标

- 不制作动画帧、新表情、骨骼动画或自动移动。
- 不保存尺寸或窗口位置。
- 不建立最终 Retina 多倍率素材体系。
- 不重新生成角色或处理细毛绿边。
- 不加入设置页、第三方依赖、AI、网络或发布配置。
