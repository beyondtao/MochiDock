# 角色设计发现与决定

## 已确认的用户决定

- 角色为小熊猫桌面宠物。
- 基础款采用圆润幼崽体型。
- 后期可以探索成长型，但首版只制作基础款。
- 飞行依靠尾巴旋转。
- 飞行风格为柔软但略笨拙的喜剧飞行。
- 基础毛色采用稍明亮的自然红棕，不使用高饱和橘色。
- 眼睛采用中等大小的圆眼，在可爱感与小熊猫辨识度之间保持平衡。
- 用户选定 `asset/character/red-panda/exploration/mochidock-red-panda-bipedal-exploration-v0.2.png` 中从左到右第二款（中间款）作为基础造型方向：圆润双足站立，双臂自然收在胸前。
- 用户确认喜欢依据中间款生成的独立母版候选 v0.3；该版本作为下一轮真实桌面尺寸验证的视觉基线，正式产品素材定稿仍需完成小尺寸和透明边缘检查。

## 设计推论

- “成长型”会影响未来的比例、服装兼容和动画复用，因此基础母版应保留稳定的面部标志与尾巴环纹，但首版不应提前承担成长系统复杂度。
- 飞行的可爱感应来自预备动作、轻微摇晃、短暂失衡和柔软尾巴形变，而不是机械化螺旋桨结构。
- 小尺寸辨识需要优先保护头部轮廓、白色面纹、深色四肢和粗条纹尾巴。
- 中等大小圆眼应保留清楚的瞳孔和小面积高光，避免过大的纯黑眼睛吞掉眼周深色特征。

## 推荐基线

- 体型：约 2.3–2.6 头身。
- 默认桌面显示高度：112–120 px。
- 验证档位：80 px、120 px、160 px。
- 设计母版：至少 2048 × 2048 px，透明背景。
- 第一阶段动画交付：透明 PNG 序列或精灵图。
- 单张透明 PNG 仅作为角色基准母版与静态姿势素材，不等于最终桌宠只能静止；需要局部动作时使用透明 PNG 帧序列，必要时再评估分层部件动画。
- 80 px、120 px、160 px 验证素材必须从同一已确认透明母版缩放生成，不分别调用图像生成，以避免角色造型和花纹漂移。
