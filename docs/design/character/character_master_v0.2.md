# 小熊猫桌面宠物角色母版 v0.2

## 一句话定义

一只圆润、活泼、略显冒失的小熊猫幼崽，会把柔软蓬松的尾巴当作螺旋桨，以不太稳定但很可爱的方式飞行。

## 首版角色边界

- 只制作基础幼崽款。
- 性格以活泼、好奇、亲近用户为主。
- 萌感优先于写实感，但保留小熊猫的物种辨识特征。
- 不制作成长系统、成长形态、服装、配件或其他性格分支。

## 身体比例

- 约 2.3–2.6 头身。
- 头部占整体高度约 38%–42%。
- 身体短圆，略呈梨形，腹部有柔软重量感。
- 四肢短而有厚度，脚掌略大，便于表现幼崽与笨拙感。
- 耳朵稍大、位置偏高，外轮廓圆润。
- 尾巴长度约为身体高度的 80%–100%，比真实小熊猫略粗。

## 固定识别点

- 稍明亮的自然红棕主毛色；保持自然、温暖，避免高饱和橘色。
- 深色腹部和四肢。
- 白色面部斑纹与耳缘。
- 深色眼周。
- 中等大小的圆眼，保留清楚瞳孔和小面积高光；不能大到遮蔽深色眼周。
- 粗而蓬松的环纹长尾巴。
- 固定尾巴环纹数量与顺序，后续形态不得随意更改。

## 飞行语言

- 起飞前先压低身体、抬起尾巴，形成明确预备动作。
- 尾巴旋转时仍保持柔软、蓬松和轻微形变，不能变成硬质机械桨叶。
- 起飞会略微偏斜或突然升高一点，角色随后努力找回平衡。
- 悬停不是完全静止，而是带有轻微上下浮动和左右晃动。
- 转向时身体先倾斜，尾巴随后调整，形成一点“反应慢半拍”的喜剧效果。
- 降落时尾巴逐渐减速，脚掌先试探地面，偶尔踉跄一下再站稳。
- 笨拙感保持轻微，不让角色显得痛苦、无能或总在失败。

## 标准母版内容

- 正面、左侧面、背面、左前 3/4、右前 3/4。
- 默认、开心、兴奋、疑惑、担心、失望、专注、成功/庆祝表情。
- 飞行预备、启动、悬停、降落四张关键姿势。
- 80 px、120 px、160 px 三档桌面缩略预览。

## 禁止项

- 禁止过度写实、成年化、修长化或人类化身材。
- 禁止把尾巴设计成金属、塑料或固定机械结构。
- 禁止为了搞笑而持续剧烈失控、摔落或表现受伤。
- 禁止弱化白色面纹、深色四肢和环纹尾巴等物种识别点。
- 禁止在基础母版上绑定永久服装或配件。
- 禁止让成长型需求提前改变首版范围。
