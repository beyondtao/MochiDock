# MochiDock 角色母版计划

## 目标

为第一阶段桌面宠物确定一套可绘制、可动画化、在小尺寸下可识别的小熊猫基础母版。

## 当前工作

- [x] 确认角色物种与桌宠定位
- [x] 确认基础体型方向：圆润幼崽
- [x] 确认首发性格：活泼、萌、略冒失
- [x] 确认飞行风格：柔软但略笨拙的喜剧飞行
- [x] 确认基础毛色方向：稍明亮的自然红棕
- [x] 确认眼睛方向：中等大小的圆眼
- [ ] 确认角色轮廓、面部花纹细节与精确色板（已选定双足探索图中间款，待生成独立母版并确认细节与色板）
- [x] 根据选定候选生成一张独立、完整、可抠图的正面 3/4 基准姿势母版（v0.3，已获用户正向确认）
- [ ] 绘制标准视图、表情表与飞行关键帧
- [x] 以 80 px、120 px、160 px 三档验证桌面可读性（v0.3 站姿与 v0.4 趴姿均已生成三档素材）
- [x] 创建趴姿静态造型候选，保持 v0.3 的头身比例、面纹、毛色和尾巴环纹（v0.4 造型已获用户确认）
- [x] 完成 v0.4 透明细毛边缘处理和 80/120/160 px 小尺寸素材生成（本地 v5 方案已获用户确认并升格）
- [x] 确认轻微呼吸/身体起伏方案：复用同一透明趴姿素材，以底部为锚点做程序化纵向缩放，不制作呼吸图片帧
- [ ] 基于同一趴姿基线制作眨眼帧
- [ ] 制作一组“开心弹起后恢复趴姿”的点击回应帧

## 可能的下一步

- 将趴姿待机与点击回应接入应用，在真实桌面上验证 30 分钟的生命感和低打扰性。
- 上述验证通过后，再评估一个有限鼠标响应。

## 创意池（未承诺）

- 成长型外观或成长阶段
- 季节服装、春节服装和可更换配件
- 安静型、火爆型等性格变体

## 明确不包含

- 首版不实现成长系统。
- 首版不制作成长后的体型或外观。
- 首版不制作服装、配件和多性格分支。
