# MochiDock 角色母版计划

## 目标

为第一阶段桌面宠物确定一套可绘制、可动画化、在小尺寸下可识别的小熊猫基础母版。

## 当前工作

- [x] 确认角色物种与桌宠定位
- [x] 确认基础体型方向：圆润幼崽
- [x] 确认首发性格：活泼、萌、略冒失
- [x] 确认飞行风格：柔软但略笨拙的喜剧飞行
- [x] 确认基础毛色方向：稍明亮的自然红棕
- [x] 确认眼睛方向：中等大小的圆眼
- [ ] 确认角色轮廓、面部花纹细节与精确色板（已选定双足探索图中间款，待生成独立母版并确认细节与色板）
- [x] 根据选定候选生成一张独立、完整、可抠图的正面 3/4 基准姿势母版（v0.3，已获用户正向确认）
- [ ] 绘制标准视图、表情表与飞行关键帧
- [ ] 以 80 px、120 px、160 px 三档验证桌面可读性

## 可能的下一步

- 将 v0.3 作为静态评估素材接入应用，验证真实桌面尺寸、辨识度、遮挡程度和长期陪伴感。
- 根据基础母版制作首批待机、移动、起飞、悬停与降落动画。
- 在真实桌面环境中验证遮挡程度、辨识度和长期陪伴感。

## 创意池（未承诺）

- 成长型外观或成长阶段
- 季节服装、春节服装和可更换配件
- 安静型、火爆型等性格变体

## 明确不包含

- 首版不实现成长系统。
- 首版不制作成长后的体型或外观。
- 首版不制作服装、配件和多性格分支。

## 待用户决定

- 独立基准母版生成后，确认面部花纹与精确色板是否定稿。

## 当前阻塞

- 第一轮 A/B/C 图是无透明通道的整张概念排版稿，包含背景、阴影和多个展示元素，不能直接拆成产品可用的独立角色素材。
- 候选方向已经选定；当前需要以中间款为参考重新生成独立基准姿势，不把探索排版稿直接裁切后用于产品。
